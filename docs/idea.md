Концепт та аналіз Mac-утиліти Context Switcher

1. Головна суть і біль, яку вирішує застосунок
   Автоматизація та повне розділення робочого й особистого простору на комп'ютері в один клік. Користувачі часто стикаються з проблемою менеджменту великої кількості вкладок, коли робочі та особисті інтереси перемішуються в одному браузері.
   Приклад використання (User Case): Користувач працює за ноутбуком, і в Chrome постійно висить окреме вікно з багатьма сайтами чисто для його особистих хобі, які доводиться постійно перемикати з робочими ресурсами. Після натискання всього однієї кнопки додаток миттєво закриває всі робочі вкладки Chrome, Slack, Zoom, корпоративну пошту та Jira. Натомість він автоматично відкриває вкладку сайту MyPidHobby, запускає умовний Fusion, особисті нотатки та навіть Steam (так, на Макбуці теж є ігри). Мізки перемикаються за секунду, і робота більше не муляє очі вечорами.
2. Аналіз ринку: Чи є сенс робити?
   Так, сенс є.
   Платоспроможна аудиторія: Користувачі Mac історично та психологічно звикли платити за софт. Вони цінують естетику, мінімалізм і готові віддати $5–$10 за утиліту в меню-барі (зверху біля годинника), якщо вона реально економить їхній час та фокус.
   Конкуренти недосконалі: Нативний менеджер вікон (Mission Control / Win + Tab) просто ховає або розпихає вікна по екранах, але не вміє керувати станом системи (закривати процеси, тушити Docker чи розділяти профілі браузера). Головний конкурент (Bunch) дуже потужний, але не має графічного інтерфейсу (UI) — конфіги треба писати руками в текстових файлах, що відлякує 90% звичайних людей.
3. Технічні варіанти розробки та хостингу ($0 на старт)
   Оскільки ліцензія розробника Apple коштує $99/рік, оптимальний план — розповсюджувати додаток через власний безкоштовний сайт у вигляді файлу .dmg або .app в обхід офіційного App Store. Для macOS це повністю легально.

4. План реалізації MVP (Мінімально життєздатного продукту)
   Написати базову логіку на C# (через Avalonia UI під Mac), яка вміє через системні команди або AppleScript відкривати/закривати задані програми та вкладки.
   Протестувати на власному кейсі (Робота ↔ Steam / Fusion / Вкладки хобі).
   Створити односторінковий сайт на GitHub Pages, підключити Stripe/Polar та опублікувати проєкт на Reddit (r/macapps) і Product Hunt.
   Технології
   .NET 10 (LTS): Основна платформа. Потрібна для високої продуктивності на Apple Silicon, суворої типізації та мінімального споживання оперативної пам'яті.
   Avalonia UI: Графічний фреймворк. Потрібен для створення легкого, кастомного інтерфейсу (через Metal/Skia) без використання важкого веб-стеку типу Electron.
   Menu Bar App Architecture: Формат утиліти. Потрібен, щоб додаток працював непомітно у фоні у верхній панелі macOS (біля годинника) і не займав місце в Dock.
   Локальний JSON (~/.config/): Спосіб збереження даних. Потрібен для миттєвого збереження конфігурацій, сесій та логів у простих текстових файлах без підключення важких баз даних.
   Додаткові NuGet-пакети:
   H.NotifyIcon.Avalonia — для створення іконки в Menu Bar та виклику вікон додатка.
   SharpHotkeys — для реєстрації глобальних гарячих клавіш у системі.
   LiveCharts2.Avalonia — для побудови легких графіків статистики.
   Microsoft.Extensions.DependencyInjection — для чистої архітектури коду (DI).
5. Повний функціонал системи (Фічі з усіх вкладок)
   Керування програмами (Запуск / Закриття): Автоматично відкриває потрібний софт та «м'яко» гасить непотрібний через AppleScript (osascript), щоб програми коректно зберігали стан (як через Cmd+Q).
   Розділення браузерних сесій: Запускає Chrome/Brave із чітко визначеним профілем через CLI-аргументи (--profile-directory), щоб повністю розділити робочі та особисті куки, вкладки й розширення.
   Глобальні гарячі клавіші: Дозволяють миттєво перемикати контексти комбінацією клавіш із будь-якого вікна в системі.
   Інтеграція з Siri (Голосове керування): Реалізується через зв'язку власного CLI додатка та нативного macOS додатка "Shortcuts" (Команди), що працює безкоштовно без ліцензії розробника Apple.
   Керування налаштуваннями macOS: Автоматично змінює шпалери столу, тему (світла/темна) та вмикає режим "Не турбувати" через системні скрипти під час зміни режиму.
   Керування медіа: Автоматично запускає плейлисти у Spotify/Apple Music через AppleScript або відкриває конкретні URL (наприклад, YouTube) відповідно до контексту.
   «Заморожування» Docker та БД: Виконує команди docker stop / docker start через C# код для гасіння важких контейнерів розробника, коли активний особистий контекст. Економить батарею та RAM.
   Контекстний Dashboard: Міні-вікно, яке випадає з Menu Bar і динамічно змінює свій інтерфейс (віджети, лінки, швидкі нотатки) залежно від увімкненого режиму.
   Статистика «Контекстного балансу»: Вбудована аналітика, яка фіксує час перебування в кожному статусі та малює графіки (Work-Life balance) на основі локальних логів через LiveCharts2.
6. Репозиторій, CI/CD та Дистрибуція
   Структура репозиторію та код
   Тип: 1 (один) публічний репозиторій на GitHub під ліцензією MIT.
   Вміст: Повністю відкритий вихідний код (.NET 10 / Avalonia UI) + готовий зібраний файл .dmg у розділі GitHub Releases.
   Філософія: Чесний Open Source. Додаток повністю функціональний і безкоштовний для тебе, друзів та спільноти.
   Процес CI/CD (Автоматизація збирання)
   Уся рутина зведена до нуля завдяки GitHub Actions:
   Ти пишеш код і робиш git push нового тегу версії (наприклад, v1.0.0).
   GitHub Actions автоматично запускає безкоштовний macOS-сервер (раннер).
   .NET 10 CLI компілює код під архітектуру Apple Silicon (arm64).
   Скомпірована програма пакується в інсталятор .dmg.
   Готовий файл .dmg автоматично публікується у розділі GitHub Releases. Результат: у тебе завжди під рукою свіжий готовий білд.
